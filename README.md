# wallace-network-scripts

Windows/Android Wi-Fi hotspot, DNS, DHCP, Roku/LG TV and network tuning scripts.

## Setup
Copy `wallace-roku-v2\config.example.json` to `config.json` and fill in your own SSID, IPs, and a path to a text file holding your hotspot passphrase. Example addresses use the 192.0.2.x / 00-00-5E-00-53-xx documentation ranges.

Run admin scripts from an elevated PowerShell. Review before running - these change network settings.
